MATNIA Tweaker
Инструмент для настройки свежей установки Windows 10 и 11. Меняет параметры системы, каждое изменение записывается и откатывается одной кнопкой.
Версия: 0.9 PRE-RELEASE (тестовая). Нужны тестеры и отзывы.
Что делает
Производительность
Игровой режим включён, фоновая запись Game DVR отключена.
Фоновые приложения Microsoft Store не работают в фоне.
Убрана задержка автозапуска, быстрее открываются меню.
Быстрее выключение, зависшие программы закрываются через 2 секунды.
Схема питания «Максимальная производительность» (по желанию, не для ноутбуков на батарее).
Приватность
Минимальный уровень телеметрии Windows.
Остановлена служба DiagTrack.
Отключены четыре задачи сбора статистики совместимости.
Отключены рекламные предложения в меню «Пуск», Bing в поиске и рекламный идентификатор.
Не запрашиваются отзывы и советы, не собирается история действий, отключены отчёты об ошибках Windows.
Интерфейс
Видны расширения файлов и скрытые файлы.
Поиск на панели задач только значком, виджеты убраны.
Очистка (необратимо)
Временные файлы пользователя.
Удаление стандартных приложений Microsoft (новости, погода, Solitaire и др.), по желанию и выключено по умолчанию.
Программы
Установка Google Chrome через winget (по желанию).
Конфиги
Полная настройка (новая система): все безопасные пункты для чистой установки, включая интерфейс Windows. Анимации не трогаются.
Плавность и чистота: производительность и приватность, анимации сохраняются.
Быстрота и чистота: то же плюс схема питания, отключение анимации сворачивания и удаление стандартных приложений.
Конфиги только отмечают пункты. Применяется всё кнопкой «Применить выбранное».
Чего не делает
Не отключает Microsoft Defender и защиту в реальном времени.
Не отключает обновления Windows и брандмауэр.
Не отправляет данные о компьютере. Журнал и откат хранятся локально.
Защита и обновления намеренно не трогаются: отключённая защита оставляет систему уязвимой.
Установка
Скачай MATNIA_Tweaker.exe из раздела Releases.
Проверь SHA-256 перед запуском (см. ниже).
Запусти файл двойным щелчком. Программа запросит права администратора.
Перед первым применением оставь включённой галочку «Создать точку восстановления».
Windows SmartScreen может показать «Неизвестный издатель», потому что файл пока не подписан сертификатом. Нажми «Подробнее» → «Выполнить в любом случае», если проверил хеш.
Проверка SHA-256
В PowerShell:
Get-FileHash .\MATNIA_Tweaker.exe -Algorithm SHA256
Сравни результат с значением, указанным в релизе.
Откат
Нажми «Откатить всё». Программа вернёт значения реестра, службы, задачи и схему питания.
Откат не возвращает удалённые приложения (их можно переустановить из Microsoft Store) и очистку временных файлов.
Если что-то пошло не так, используй точку восстановления Windows, которую программа создаёт перед изменениями.
Удаление программы не откатывает изменения. Сначала нажми «Откатить всё».
Важно
Схема «Максимальная производительность» заметно сокращает время работы ноутбука от батареи.
Перезагрузи компьютер после применения настроек.
Программа протестирована синтаксически, полные тесты на разных сборках Windows пока не проводились. Отзывы помогают.
